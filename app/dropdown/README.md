# Component.13 — Dropdown

An anchored document menu that opens from its trigger's top-left corner. The hover highlight is a single shared element that springs between rows rather than fading in per item, so moving down the list reads as one continuous motion. Unhovered rows dim to 55% opacity, which keeps the pointer's position legible at thumbnail size. Keyboard navigation (↑↓, ⏎, Esc) drives the same highlight, and the destructive row carries the rust accent — the only color in the piece.
