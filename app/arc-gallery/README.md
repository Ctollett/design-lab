# Effect.3 — Arc Gallery

Nine plates laid along a parabola: horizontal position is linear in the index offset, vertical drop is quadratic, and scale falls off with distance from centre — so the stack reads as an arch with the centre plate largest and nearest. Pointer x drives a single spring-damped `center` value that every plate derives its transform from, which means the whole arch traverses as one body and reverses mid-travel without finishing its arc. Hovering lifts a plate and desaturates its neighbours; the nav sits in the negative space the parabola leaves beneath the centre.
