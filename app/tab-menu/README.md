# Component.14 — Tab Menu

Three tabs over a single card. The active pill is one shared element that springs between positions instead of appearing and disappearing, and the panel below cross-fades on a short vertical offset so the direction of the change is readable. Content is a Braun T 1000 spec sheet — mono small caps for the metadata line, editorial serif for the subject, sans for the body.

```
Component.14 — Tabbed panel with a spring-tracked selection pill.

The pill is a single travelling element, so switching tabs reads as one
continuous move rather than two fades.

Made with @reactjs, @motiondotdev.
```
